# ROLY-POLY Pocket Racing

スマートフォンをハンドルにして遊ぶ、ブラウザ向け3Dドライブゲームです。

PCにゲーム画面を表示し、同じWi-Fiにつないだスマートフォンを傾けてハンドル操作します。アクセル、ブレーキ、クラクション、レース開始もスマートフォンから操作できます。

## 特徴

- Three.jsによる三人称視点の3Dドライブ
- スマートフォンのジャイロセンサーを使ったハンドル操作
- スマートフォン画面のアクセル、ブレーキ、クラクション
- QRコードによるPCとスマートフォンの接続
- WebRTC DataChannelによる低遅延な端末間通信
- 3周レース、スタートカウントダウン、ラップタイム、合計タイム
- コース外での減速と、木・建物の衝突判定
- GitHub Pagesで静的ホスティング可能
- ゲーム中の操作データを外部サーバーへ保存しないローカル構成

## 必要なもの

- PC
- ジャイロセンサーを搭載したスマートフォン
- PCとスマートフォンが接続できる同一のWi-Fiネットワーク
- カメラとモーションセンサーを利用できるブラウザ

スマートフォンのカメラとモーションセンサーを利用するため、実機で遊ぶページはHTTPSで配信する必要があります。GitHub PagesとngrokはどちらもHTTPSに対応しています。

## 遊び方

1. PCでゲームページを開きます。
2. PCに表示された「① スマホ用ページを開くURL」のQRコードを、スマートフォンの標準カメラで読み取ります。
3. PCで「② 接続QRを表示」を押します。
4. スマートフォンで「カメラを開く」から「② 接続QR」を読み取ります。
5. スマートフォンに表示された「③ 返答QR」をPCのカメラで読み取ります。
6. 接続完了後、スマートフォンを横向きにします。
7. 構え方の案内を確認し、「準備できた」を押します。
8. スマートフォンを胸の前でまっすぐ構え、`START`を押します。
9. PCのカウントダウンが終わったらレース開始です。

`START`を押したときのスマートフォンの向きが、ハンドルの中央位置として設定されます。再スタート時も同様に中央位置が設定し直されます。

## 接続の仕組み

このゲームはBluetoothではなく、WebRTC DataChannelを使ってPCとスマートフォンを直接接続します。

QRコードは、WebRTCの接続情報を端末間で交換するために使用します。接続後は、ハンドル、アクセル、ブレーキ、クラクション、STARTの入力がスマートフォンからPCへ直接送られます。

## ローカルで起動する

### 必要な環境

- Node.js 22.13以上
- pnpm 11

### セットアップ

```bash
pnpm install
pnpm dev:github
```

ブラウザで次のURLを開きます。

```text
http://localhost:5173/
```

PC上だけで表示を確認する場合は、localhostのままで利用できます。

## スマートフォンで実機確認する

ローカル開発サーバーを起動した状態で、別のターミナルからngrokを実行します。

```bash
ngrok http 5173
```

表示されたHTTPS URLをPCで開いてください。PC画面に表示されるQRコードから、スマートフォン用ページを開けます。

## GitHub Pagesへ公開する

このリポジトリにはGitHub Pages用のワークフローが含まれています。

1. GitHubにリポジトリを作成します。
2. このプロジェクトを`main`ブランチへpushします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Source** に **GitHub Actions** を選択します。
5. Actionsのデプロイ完了後、発行されたURLをPCで開きます。

`main`ブランチへpushするたびに、GitHub Actionsが次の処理を自動実行します。

```bash
pnpm install --frozen-lockfile
pnpm build:github
```

公開用ファイルは`docs`ディレクトリへ生成されます。

## トラブルシューティング

### スマートフォンのカメラやジャイロが動かない

- HTTPSのURLで開いているか確認してください。
- ブラウザのカメラ・モーションセンサー権限を許可してください。
- iPhoneでは、`START`を押したときに表示されるセンサー利用確認を許可してください。

### PCとスマートフォンが接続できない

- 両方が同じWi-Fiに接続されているか確認してください。
- VPNや通信を遮断するブラウザ拡張機能を一時的に無効にしてください。
- PCとスマートフォンのページを両方再読み込みし、①から接続をやり直してください。
- QRコードは、画面に表示された番号の順番どおりに読み取ってください。

### スマートフォンで全画面にならない

モバイルブラウザによっては、通常のWebページの全画面表示が制限されています。iPhoneでは、ページをホーム画面へ追加して起動すると、より広い表示領域を利用できます。
